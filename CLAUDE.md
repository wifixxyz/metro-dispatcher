# CLAUDE.md — правила автономной работы

## Проект
Игра «Метро · Диспетчер».
- Требования: `docs/SPEC.md`
- План: `docs/ROADMAP.md`
- История: `CHANGELOG.md`

## Чтение контекста
- В начале работы читай ROADMAP и CHANGELOG.
- SPEC — только нужные разделы.
- `reference/v7.5.html` целиком не читай, только `grep`.

## Цикл одной итерации
1. `git checkout main && git pull`; создай ветку `iter-N-<кратко>`.
2. Реализуй итерацию N из ROADMAP, ничего сверх неё.
3. Гоняй `npm run typecheck`, `lint`, `test`, `build`, пока всё не станет зелёным.
4. Подними версию (minor), запиши в CHANGELOG, отметь статус в ROADMAP.
5. Push, `gh pr create` с отчётом: изменения + таблица проверок с цифрами (только реально запущенное).
6. `gh pr checks --watch`; если CI красный — чини и пушь снова.
7. Зелёный CI → `gh pr merge --squash --delete-branch`, вернись на main.

## Зависимости
Ставь через `npm install`, коммить `package-lock.json`.

## Нельзя
- `git push --force`
- коммиты напрямую в main (кроме этого CLAUDE.md)
- правки `.github/workflows` без необходимости
- удаление `reference/`

## Если застрял
Если требование неоднозначно или итерацию не получается довести за разумное время — остановись и опиши проблему в `ISSUES.md` вместо того, чтобы гадать.

## Стиль ответов
Отвечай по-русски, коротко.
