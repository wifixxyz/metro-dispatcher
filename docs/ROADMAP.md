## Правила итераций

- Каждая итерация заканчивается рабочей задеплоенной версией.
- Версия по semver (с 0.1.0), запись в CHANGELOG.md.
- В конце — отчёт: ссылка на PR, ссылка на игру, список изменений,
  таблица проверок с цифрами (только то, что реально запускалось).
- Функции сверх текущей итерации — только по согласованию.
